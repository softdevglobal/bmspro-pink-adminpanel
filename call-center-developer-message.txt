BMS Pro Pink — Call center / reception chat APIs
================================================

Replace BASE with your deployed Pink admin origin (e.g. https://admin.example.com).

Auth: Authorization: Bearer <Firebase ID token> (same Firebase project as Pink).
Call-center routes use CORS Access-Control-Allow-Origin: * like Black.

------------------------------------------------------------
LIST SALONS (SALON OWNERS) — two equivalent entry points
------------------------------------------------------------

1) Full or summary workshop list (recommended; matches Black)

   GET BASE/api/call-center/workshops?summary=1
   → JSON { "workshops": [ ... ] }  — lightweight owner rows (ownerUid, name, slug, logoUrl, contactPhone, email, timezone, state, accountStatus).

   GET BASE/api/call-center/workshops
   → JSON { "workshops": [ ... ] }  — full bundle per salon (workshop + branches + services + staff; Pink shape, no vehicle-type fields).

2) Chat-focused light list (same underlying owner query; key name differs)

   GET BASE/api/call-center/chats/workshop-owners
   → JSON { "workshopOwners": [ ... ] }  — same style of summary rows as (1) summary mode.

Dev: on localhost, unauthenticated listing may be enabled unless CALL_CENTER_DEV_LIST_ALL_WORKSHOPS=false.
